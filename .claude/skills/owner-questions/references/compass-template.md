# Компас проекта — шаблон `specs/compass.md`

Компас — не спецификация, а то, чем решают спорное, когда спецификация
молчит. Короткий: одна страница. Образцы — `product.md` в Kiro, `constitution.md`
в GitHub Spec Kit. Заполняется с владельцем вопросами о ценностях: у каждого
вопроса твоя гипотеза, владелец подтверждает или поправляет.

```markdown
# Компас: <проект>

## Зачем
Одно-два предложения: зачем продукт существует.

## Для кого и какую работу делает
- <пользователь>: хочет <прогресс>, сейчас мешает <что>.

## Ценности
3–7 пунктов. У каждого — что это значит на практике и пример нарушения.

## Правила компромиссов
Пары «A против B — что важнее и когда», по порядку.

## Чего продукт сознательно не делает
- …

## Прецеденты
Ответы владельца, ставшие правилом: дата, правило, откуда (issue или обсуждение).
- 2026-10-02 — …
```

Вопросы для сбора (по одному на раздел, с гипотезой):
1. Кто главный пользователь и что он пытается сделать?
2. Что для него провал? (Отсюда ценности.)
3. Что важнее, если нельзя всё сразу: скорость, надёжность, простота, полнота?
4. Чего продукт точно не должен делать?
5. Кто решает спорное и сколько внимания он готов тратить?
