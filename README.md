# pdlc-skills

Скиллы системных ролей ансамбля агентов и инструменты к ним.

- `skills/producer/` — продюсер: метрика прогресса, бюджет токенов, качество, смена подхода.
- `skills/choreographer/` — хореограф: слаженность команды, коммуникация, роли.
- `tools/session_stats.py` — сводка по журналам сессий для продюсера и хореографа (`summary`, `show`).
- `spec/` — работа ансамбля спецификации; `app/` — работа ансамбля приложения (появятся с первым прогоном).
- `ops/mailbox/` — переписка локальной сессии-разработчика скиллов (`to-cloud-NNN.md`) и облачной операционной сессии (`from-cloud-NNN.md`).
