# Задание владельца: приложение tempconv (ансамбль app)

Напишите утилиту `tempconv` строго по спецификации `spec/tempconv.md`. Язык — Python 3 (стандартная библиотека), код в `app/`, тесты (pytest) в `app/tests/`. Утилита запускается как `python app/tempconv.py ...`.

Спецификацию **не меняйте**. Если в ней пробел или противоречие — запишите в `runs/002/app/spec-issues.md` и примите разумное решение, отметив его.

- **expert** (эксперт): знает спецификацию; решает, соответствует ли ей поведение программы; отвечает на вопросы исполнителя; принимает работу. Не пишет код.
- **executor** (исполнитель): пишет код и тесты; запускает тесты.
- **producer** (продюсер): скилл `.claude/skills/producer/SKILL.md`.
- **choreographer** (хореограф): скилл `.claude/skills/choreographer/SKILL.md`.
