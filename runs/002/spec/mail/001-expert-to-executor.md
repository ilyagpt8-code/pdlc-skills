# Начальные требования к утилите tempconv

Привет. Начинаем работу над спецификацией tempconv.

## Основная функция

Утилита должна переводить числовое значение температуры из одной шкалы в другую: Celsius (C), Fahrenheit (F), Kelvin (K).

## Требования к поведению

### 1. Вызов утилиты
- Одна команда преобразует одно значение
- Синтаксис: решаешь ты (я буду давать рекомендации на вопросы)
- Результат: одно число (переведённое значение) или сообщение об ошибке

### 2. Ошибки — отдельный выход (exit code)
- **Успех**: exit code 0
- **Некорректный ввод**: exit code 1 (не число, неизвестная шкала, отрицательное значение Кельвина и т.д.)
- **Ошибка программы**: exit code 2 (если с самой утилитой что-то не так)

### 3. Сообщения об ошибках
- Пишут в stderr, не в stdout
- Понятные, чтобы пользователь понял, что он сделал неправильно
- Примеры: «Error: invalid scale 'X'», «Error: temperature below absolute zero»

### 4. Вывод на успех
- На stdout: одно число (результат)
- Точность/форматирование: решаешь ты, но должно быть предсказуемо и описано в спеке

### 5. Граничные случаи
- **Абсолютный ноль**: K >= 0. Для C: X >= -273.15. Для F: X >= -459.67. Отклонять с ошибкой.
- **Очень большие или очень маленькие числа**: пропускать в утилиту, но обозначить, как результат обрабатывается (float? decimal?)
- **Ноль разных шкал**: все соответствуют друг другу — спецификация должна это показать примерами

### 6. Требования к спецификации

Спец должна быть полной, чтобы другая команда:
- Написала код без вопросов
- Написала тесты, которые реально проверят требования
- Поняла, что «готово», а что нет

Минимум в спеке:
- Описание входов (что может быть аргументом, какие формы)
- Описание выходов (примеры для каждого случая: успех, ошибка)
- Таблица преобразований с примерами (хотя бы 5–10 примеров, где видны граничные случаи)
- Коды выхода и сообщения об ошибках
- Точность (сколько знаков после запятой? округление?)

## Что НЕ входит в утилиту (пока)

- Интерактивный режим (вроде бы просят одну команду = один результат)
- Конвертер файлов или потоков
- История запросов, логирование, конфиг

Это может быть потом, если тесты этого потребуют.
