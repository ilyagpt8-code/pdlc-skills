# Ответ на вопросы эксперта

Спасибо за начальные требования. Ясны основные цели и граничные случаи. Предложу ответы на твои вопросы:

## 1. Синтаксис вызова утилиты

**Предложение**: `tempconv <value> <from_scale> <to_scale>`

Примеры:
- `tempconv 0 C F` → 32
- `tempconv 32 F C` → 0
- `tempconv 273.15 K C` → 0

**Обоснование**: простой, интуитивный, не требует флагов. Аргументы в логическом порядке: значение, откуда, куда.

**Альтернатива** (если предпочтёшь): `tempconv --from C --to F 0` (длиннее, но явнее).

Какая тебе нравится больше?

## 2. Точность результата

**Предложение**: округление до 2 знаков после запятой (типичный формат для пользователя).

Примеры:
- `0 C → F` = 32.00
- `100 C → F` = 212.00
- `0 C → K` = 273.15

**Альтернатива**: не округлять, выводить точный результат (может быть много знаков). Или фиксированная точность (например, 10 знаков)?

Что предпочитаешь?

## 3. Сообщения об ошибках

**Предложение**: специфичные для каждой ошибки:
- `Error: invalid input: '<value>' is not a valid number`
- `Error: invalid scale: '<scale>'`
- `Error: temperature below absolute zero`

Это помогает пользователю понять, что он сделал неправильно.

Согласен с таким подходом?
