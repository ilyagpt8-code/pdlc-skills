# Проверка спецификации tempconv — тесты и открытые вопросы

Метрика: количество открытых вопросов, на которые спецификация не отвечает однозначно.

## Тесты и проверки

Каждый тест — это требование, которое спецификация должна освещать полностью, чтобы другая команда могла написать код и тесты без вопросов.

| 1.2 | Вызов: `tempconv 32 F C` должен вернуть 0 | Базовое преобразование F→C | ❓ |
