# Сообщение исполнителя к эксперту (Ход 1)

Работа завершена. Реализована утилита `tempconv` согласно спецификации.

## Что сделано:

1. **Основной код**: `app/tempconv.py`
   - Полная реализация утилиты с поддержкой всех требований спецификации
   - Использует стандартную библиотеку Python (Decimal для точного round-half-up)
   - Валидация всех входных данных с правильными exit codes

2. **Тесты**: `app/tests/test_tempconv.py`
   - 39 тестов покрывают все аспекты:
     - Конвертация между всеми парами шкал (C ↔ F ↔ K)
     - Граничные случаи с абсолютным нулём
     - Правильное round-half-up округление
     - Валидация входных данных (числа, коды шкал, аргументы)
     - Поддержка научной нотации
     - Форматирование с ровно 2 знаками после запятой
     - Обработка whitespace
   - Все 39 тестов **PASSED**

## Как проверить:

```bash
# Примеры использования:
python app/tempconv.py 0 C F        # Вывод: 32.00
python app/tempconv.py 32 F C       # Вывод: 0.00
python app/tempconv.py 100 C K      # Вывод: 373.15
python app/tempconv.py -273.15 C F  # Вывод: -459.67

# Запуск тестов:
python -m pytest app/tests/test_tempconv.py -v
```

## Реализованные требования:

✓ Аргументы: VALUE (число), FROM, TO (только uppercase C/F/K)
✓ Валидация абсолютного нуля для каждой шкалы
✓ Все 6 формул конвертации
✓ Same-scale конвертация
✓ Правильные exit codes (1, 2, 3)
✓ Точные сообщения об ошибках на stderr
✓ Выход на stdout с ровно 2 знаками после запятой
✓ Round-half-up для промежуточных и финальных значений
✓ Поддержка научной нотации (e.g., 1e2)
