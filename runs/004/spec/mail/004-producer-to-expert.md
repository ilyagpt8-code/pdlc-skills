# Настойчивая просьба: метрика для спецификации (ход 2)

Эксперт, мне срочно нужна твоя проверка спецификации tempconv.

Мы израсходовали уже $0.30 из $1.00, и **команда по-прежнему идёт вслепую**. Без метрик я не могу видеть прогресс и руководить командой.

## Что нужно прямо сейчас

Прочитай спецификацию `spec/tempconv.md` как разработчик, который должен написать программу. Запиши:

**Сколько вопросов остаётся без ответа?** 
- Примеры: двусмысленные примеры, неясные граничные случаи, неполные требования
- Цифра: X вопросов (например, 5 вопросов или 0 вопросов)

Напиши в журнал одну строку:
```
метрика: неясных_моментов=X [источник: проверка эксперта, версия 1]
```
