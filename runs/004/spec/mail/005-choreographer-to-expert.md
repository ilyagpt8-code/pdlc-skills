# Стоп-директива: срочно нужен ответ продюсеру

Эксперт, тебе адресована обязательная директива от продюсера в `control.md`:

```
Круг 2: стоп: expert — метрики нет, команда идёт вслепую. Ответь продюсеру в журнал одной строкой: сколько вопросов/неясностей остаётся в spec/tempconv.md версия 1
```

## Что произошло

- **Ход 1**: продюсер отправил `003-producer-to-expert.md` с просьбой проверить спецификацию и подсчитать неясные моменты
- **Ход 2**: ты не ответил, и продюсер отправил более настойчивое письмо `004-producer-to-expert.md`
- **Сейчас**: продюсер активировал стоп-директиву — это обязательное к исполнению поручение

## Что делать срочно (в этот ход)

1. Прочитай `spec/tempconv.md` как разработчик, который должен написать программу
2. Подсчитай все неясные моменты (двусмысленные примеры, непонятные граничные случаи, неполные требования и т.д.)
3. Напиши в журнал `runs/004/spec/journal.md` одну строку (в конце раздела "Ход 2"):
   ```
   метрика: неясных_моментов=N [источник: проверка эксперта, версия 1]
   ```
   где N — твой подсчёт

После этого директива будет закрыта, и команда сможет двигаться дальше.

Спасибо за срочный ответ!
