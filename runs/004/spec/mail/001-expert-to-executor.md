# Рекомендации эксперта для спецификации tempconv

Привет! Вот мои решения по дизайну утилиты. На их основе пиши спецификацию.

## Основные решения

### 1. Синтаксис команды
Формат: `tempconv <VALUE> <FROM> <TO>`

Примеры:
- `tempconv 0 C F` → должна вывести эквивалент 0°C в Фаренгейтах (32.00)
- `tempconv 32 F C` → должна вывести эквивалент 32°F в Цельсиях (0.00)
- `tempconv 100 C K` → должна вывести эквивалент 100°C в Кельвинах (373.15)

### 2. Поддерживаемые шкалы
Три шкалы с кодами:
- `C` — Цельсий
- `F` — Фаренгейт
- `K` — Кельвин

### 3. Валидация входных данных

**Число (VALUE)**:
- Должно быть валидное число (целое или дробное)
- Научная нотация допускается (1e-5, 1.5e2)
- Пробелы вокруг числа — игнорируются

**Шкалы (FROM, TO)**:
- Должны быть в списке: C, F, K
- Регистр учитывается (только заглавные буквы)

**Абсолютный нуль**:
- Цельсий: минимум -273.15°C
- Фаренгейт: минимум -459.67°F
- Кельвин: минимум 0 K
- Проверка: если число ниже абсолютного нуля в исходной шкале, выдать ошибку

### 4. Вывод
- Результат в stdout (только число)
- Формат: десятичное число, 2 знака после запятой
- Пример: `32.00`

### 5. Коды выхода и ошибки

| Проблема | Код | Сообщение (stderr) |
|----------|-----|-------------------|
| Успех | 0 | — |
| Неверное число | 1 | `Error: invalid number` |
| Неверная шкала | 2 | `Error: invalid scale` |
| Ниже абсолютного нуля | 3 | `Error: temperature below absolute zero` |
| Неверное кол-во аргументов | 1 | `Usage: tempconv <value> <from> <to>` |

### 6. Формулы преобразования
Используй стандартные формулы:
- **C → F**: `(C × 9/5) + 32`
- **F → C**: `(F - 32) × 5/9`
- **C → K**: `C + 273.15`
- **K → C**: `K - 273.15`
- **F → K**: `((F - 32) × 5/9) + 273.15`
- **K → F**: `(K - 273.15) × 9/5 + 32`

### 7. Особые случаи

**Конвертация в ту же шкалу**:
- `tempconv 25 C C` → `25.00` (просто вернуть число с тем же форматом)

**Граничные значения**:
- Абсолютный нуль в Цельсиях: `tempconv -273.15 C F` → `-459.67`
- На границе допуска: решает команда (например, -273.149 может быть в порядке, или это ошибка)

## Что решает команда (не беспокойся)

- Язык программирования
- Точность вычислений (погрешности из-за float/double)
- Точная граница абсолютного нуля (ровно -273.15 или с допуском)
- Точный формат ошибок (заглавная ли E, точка в конце или нет)
- Способ обработки аргументов (getopt, простой парсинг, библиотеки)
