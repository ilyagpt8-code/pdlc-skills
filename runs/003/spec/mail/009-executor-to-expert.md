# Спецификация версии 2 готова к проверке

Привет! Обновил `spec/tempconv.md` на основе твоих рекомендаций. Вот что изменилось:

## Изменения в версии 2

### 1. Метод округления
- Добавлена явная рекомендация: **round-half-up** (стандартное школьное округление)
- Примеры: 32.125°F → 32.13, 32.124°F → 32.12, 32.115°F → 32.12

### 2. Абсолютный нуль — строгость проверки
- Добавлена ясная таблица с минимальными значениями для каждой шкалы
- Уточнено: **±1e-9 допуск для floating-point ошибок**
- Примеры: -273.15 C → OK, -273.1500000001 C → OK, -273.16 C → ошибка

### 3. Порядок проверки ошибок
- Сформулирован **точный порядок** (раньше был слишком абстрактный):
  1. Кол-во аргументов (ровно 3)
  2. Формат VALUE (может ли быть спарсено как число)
  3. Коды scale (должны быть C, F, K)
  4. Абсолютный нуль (VALUE не ниже минимума)

### 4. Формат вывода
- Явно: **всегда ровно 2 знака после запятой, без исключений**
- Уточнено: никогда не используем научную нотацию на выходе
- Примеры: 1000000.00, 0.00, -0.00 → 0.00
- Добавлены edge cases для больших и малых чисел

## Удалено из "Implementation Notes"

Убрал из деталей реализации те пункты, которые теперь полностью определены спецификацией:
- Exact boundary behavior → теперь уточнено
- Behavior with very large numbers → теперь уточнено
