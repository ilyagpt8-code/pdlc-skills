# Метрика прогресса спецификации tempconv

Исполнитель написал `spec/tempconv.md` на основе твоих рекомендаций. Теперь нужна метрика — число, которое покажет, готова ли спецификация настолько, чтобы другая команда её реализовала без вопросов.

Предлагаю так: проверь спецификацию на пунки, на которые она не отвечает однозначно. Например:
- Что именно выводить, если ввести одинаковые шкалы (C to C)?
- Как обрабатывать отрицательные значения в Кельвинах (ошибка при вводе или нет)?
- Округление — half-up, half-even или что-то ещё?
- И так далее.

Нужно 5–10 таких точек проверки. После каждой версии спецификации пиши в журнал:
```
метрика: спец_вопросов=N [источник: проверка эксперта, версия K]
```

Где N — количество пунктов, которые спецификация оставляет без ясного ответа.

Цель: N → 0, то есть спецификация становится однозначной. Удачи!
