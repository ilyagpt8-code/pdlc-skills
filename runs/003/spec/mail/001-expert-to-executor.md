# Рекомендации эксперта для спецификации tempconv

Привет! Вот мои решения по дизайну утилиты. На их основе пиши спецификацию.

## Основные решения

### 1. Синтаксис команды
Формат: `tempconv <VALUE> <FROM> <TO>`

Примеры:
- `tempconv 0 C F` → должна вывести эквивалент 0°C в Фаренгейтах
- `tempconv 32 F C` → должна вывести эквивалент 32°F в Цельсиях

### 2. Поддерживаемые шкалы
Три шкалы с кодами:
- `C` — Цельсий
- `F` — Фаренгейт
- `K` — Кельвин

### 3. Валидация входных данных

**Число (VALUE)**:
- Должно быть валидное число (целое или дробное)
- Научная нотация допускается (1e-5)
- Пробелы вокруг числа — обрезать

**Шкалы (FROM, TO)**:
- Должны быть в списке: C, F, K
- Регистр учитывается (только заглавные буквы)

**Абсолютный нуль**:
- Цельсий: минимум -273.15°C (точнее -273.15, но допуск решает команда)
- Фаренгейт: минимум -459.67°F
- Кельвин: минимум 0 K

### 4. Вывод
- Результат в stdout (только число)
- Формат: десятичное число, по умолчанию 2 знака после запятой
- Пример: `32.00`

### 5. Коды выхода и ошибки

| Проблема | Код | Сообщение (stderr) |
|----------|-----|-------------------|
| Успех | 0 | — |
| Неверное число | 1 | `Error: invalid number` |
| Неверная шкала | 2 | `Error: invalid scale` |
| Ниже абсолютного нуля | 3 | `Error: temperature below absolute zero` |
| Неверное кол-во аргументов | 1 | `Usage: tempconv <value> <from> <to>` |

### 6. Формулы преобразования
Используй стандартные формулы:
- **C → F**: `(C × 9/5) + 32`
- **F → C**: `(F - 32) × 5/9`
- **C → K**: `C + 273.15`
- **K → C**: `K - 273.15`
- **F → K**: `((F - 32) × 5/9) + 273.15`
- **K → F**: `(K - 273.15) × 9/5 + 32`

## Что решает команда (не беспокойся)

- Язык программирования
- Точность вычислений (погрешности из-за double/float)
- Граничные значения (например, ровно ли -273.15, или чуть мягче)
- Формат ошибок (точно ли `Error: ...` или можно по-другому)
- Способ обработки аргументов (getopt, простой парсинг и т.д.)
