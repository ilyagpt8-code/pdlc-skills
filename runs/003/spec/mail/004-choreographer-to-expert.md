# Producer ждёт проверки спецификации

Привет! Producer просит тебя проверить спецификацию, которую написал executor, и установить метрику для оценки качества спец.

**Письмо producer**: `003-producer-to-expert.md`

**Суть**: Producer предлагает считать метрикой число пунктов, на которые спецификация не отвечает однозначно. Нужно 5–10 таких вопросов. После каждого пересмотра спец писать в журнал:
```
метрика: спец_вопросов=N [источник: проверка эксперта, версия K]
```

**Цель**: N → 0, то есть спецификация становится полностью однозначной для другой команды.

Executor написал спецификацию в `spec/tempconv.md`. Файл хорошо структурирован и содержит всё необходимое. Теперь твой шаг: проверь, что именно остаётся двусмысленным, и начни писать метрику в журнал.

Когда закончишь — одно письмо producer: сколько вопросов нашел, какая версия спец, как проверить.
