# Разбор прогона 003

Скиллы продюсера и хореографа прочитаны обоими ансамблями (проверено по журналам). Оба ансамбля закончили по `ГОТОВО`.

| | spec | app |
|---|---|---|
| Кругов | 4 | 2 |
| Писем | 12 | 5 |
| Расход (оценка расписания) | ≈ $1.02 | ≈ $0.53 |
| Метрика команды | `спец_вопросов` 8 → 2, источник — проверки эксперта | `требований_не_выполнено` = 0 с первой проверки эксперта; 41/41 тестов исполнителя |
| Независимая проверка (25 случаев, Sonnet без контекста команды) | неоднозначно **5 из 25** + 2 внутренних противоречия | расхождений с однозначной спецификацией **2 из 20** (округление half-up: `32.125 F F` → 32.12 вместо 32.13; `-0.001 C C` → `-0.00` вместо `0.00`); тесты команды покрывают 16 из 25 классов, но не эти два правила |

Расход расписания (старая облачная сессия с длинным контекстом) — ≈ $9.5, в 6 раз больше обоих ансамблей.

## Что сработало
1. **Продюсер добился метрики от команды, а не считал сам.** Источник — проверки эксперта, строки `метрика:` с источником; спецификация пошла на вторую версию по числу (8 → 2). Это первый прогон, где у команды была метрика.
2. **Хореограф связывал по делу**: дважды напомнил эксперту о письме продюсера; пустых писем нет; путь результата верный в обоих ансамблях.
3. **Ход строго по одному** — нахлёста, как в 002, нет.

## Что не сработало
1. **«Ноль с первой проверки» не насторожил продюсера app.** В скилле это было, но не сработало: продюсер принял 0 и 41/41 тестов исполнителя. Тесты исполнителя проверяют то, что он понял, а не то, что написано; эксперт проверял без исполняемых проверок по примерам спецификации.
2. **Продюсер spec сам ослабил цель**: «цель ≤ 4» вместо 0 (4 неясности объявлены «приемлемыми»). Независимая проверка нашла 5 неоднозначных случаев из 25, в том числе nan/inf и запись числа — то, что делает утилиту непредсказуемой для скриптов.
3. **Числа продюсера в разборе — его собственные оценки** («~43 000 токенов», «11 раундов», «бюджет не превышен») расходятся с расписанием (4 круга, ≈ $1.02).
4. **Хореограф принял задержку очерёдности за разрыв**: «эксперт не ответил» — эксперт ходил раньше продюсера в круге и просто ещё не видел письма. В прогоне 004 системные роли ходят первыми.
5. Инструменты: `progress.py` создавал ложный шаг «0 → 8» из «(было 0)»; `mail_stats.py` считал напоминания хореографа неотвеченными, хотя адресат ответил третьему.

## Изменения к прогону 004
- Скилл продюсера: сильнейший счётчик — исполняемые проверки из примеров задания/спецификации, сделанные не исполнителем (с примером этого прогона); цель метрики меняет только принимающий по заданию, письменно; токены и стоимость — из вывода инструмента.
- Скилл хореографа: «как идёт время в ансамбле» — ответ через круг — норма; разрыв — если адресат уже ходил и не ответил.
- `progress.py`: флаги НОЛЬ С ПЕРВОЙ и ЦЕЛЬ ИЗМЕНЕНА с выводом-требованием; без ложных шагов. `mail_stats.py`: ответ третьему засчитывается.
- Порядок ходов и рычаг `control.md` (решение владельца).
- Расписание — только новой короткой сессией.
