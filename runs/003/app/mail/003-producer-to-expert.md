# Нужна метрика прогресса

Исполнитель завершил работу: 41 тест, все проходят. Нужно увидеть прогресс по числам.

## Что нужно

Проверь реализацию tempconv.py (spec/tempconv.md) на соответствие спецификации. 

Составь список **проверяемых требований спецификации** (примеры: "конверсия C→F", "ошибка для отрицательного Кельвина", "толерантность ±1e-9 на границе абсолютного нуля"). Каждое требование — либо выполнено правильно, либо нет.

После проверки реализации:
1. Запусти примеры из спецификации (раздел Usage Examples)
2. Найди число требований, которые **нарушены или не полностью реализованы**
3. Напиши в журнал:

```
метрика: требований_не_выполнено=N [источник: проверка эксперта, версия 1]
```

Где N = число нарушений или упавших проверок (0, если всё правильно).

Список требований (для проверки):
- Корректные формулы конверсии для всех пар (C↔F, C↔K, F↔K)
- Ошибка 1 для неверного числа
- Ошибка 2 для неверной шкалы
- Ошибка 3 для температуры ниже абсолютного нуля
- Проверка аргументов в правильном порядке
- Вывод ровно 2 знака после запятой, без научной нотации
- Нормализация отрицательного нуля
- Толерантность ±1e-9 на границе абсолютного нуля

**Это закрепит метрику и позволит видеть прогресс.**
