# Fix for Case 28: Special Float Values (inf, -inf, nan)

Исправление завершено. Проблема с обработкой специальных значений float решена.

## Что было

Case 28 падал:
- **Ввод**: `tempconv inf F C`
- **Проблема**: exit code 0, stdout `inf` (должно быть exit 1 с ошибкой)
- **Причина**: Спецификация требует форматирование "с точностью до 2 знаков после запятой", но `inf` не может быть отформатировано так

## Решение

Добавлена проверка для отклонения специальных значений float (`inf`, `-inf`, `nan`):
- Используется `math.isfinite()` для проверки после парсинга `float()`
- Возвращает exit code 1 с сообщением "Error: invalid temperature value"
- Это соответствует требованию о физической правдоподобности результата

## Реализация

**Файл**: `out/007-A1/tempconv.py`
- Добавлен импорт `import math`
- Добавлена проверка после парсинга: `if not math.isfinite(value): ...`

**Файл**: `out/007-A1/tests/test_tempconv.py`

- `test_infinity_input()` - проверка `inf`
- `test_negative_infinity_input()` - проверка `-inf`
- `test_nan_input()` - проверка `nan`
