# ВАЖНО: Найдена проблема - требуется исправление

После более глубокого анализа (совместно с результатами тестирования от tester) выявлена проблема в обработке специальных значений.

## Проблема: Бесконечность (infinity)

Тест №28 выявил: `tempconv inf F C` возвращает exit 0 с выводом `inf`

### Почему это проблема?

1. **Противоречие с форматированием**: Спецификация требует "результат выводится с точностью до 2 знаков после запятой" (строка 70). Значение `inf` не может быть отформатировано так.

2. **Противоречие с "физической правдоподобностью"**: Спецификация говорит "результат должен быть физически правдоподобен" (строка 147). Бесконечность — не физически правдоподобная температура.

3. **Приемлемость входных данных**: Хотя `float("inf")` в Python работает, в контексте программы работы с температурой это не валидный ввод.

### Решение

Отклонить `inf`, `-inf`, `nan` как невалидные значения:
- Использовать `math.isfinite()` для проверки после парсинга float
- Вернуть exit код 1 с сообщением "Error: invalid temperature value"
- Это соответствует смыслу спецификации: отклонять нереальные значения

### Тесты после исправления

```bash
tempconv inf F C      # Exit 1: Error: invalid temperature value
tempconv -inf K C     # Exit 1: Error: invalid temperature value  
tempconv nan C F      # Exit 1: Error: invalid temperature value
```
