## Результат проверки: пропуск №28

**Тест 28:** `inf F C`
**Ожидается:** exit code 1 (ошибка) или правильный формат числа
**Получено:** exit code 0, stdout: `inf`
**Проблема:** 
- Python float() принимает 'inf' как валидное число
- Программа выводит 'inf' в stdout
- Спецификация требует: "Результат выводится с точностью до 2 знаков после запятой" с удалением лишних нулей
- 'inf' не является валидным форматом числа по правилам спецификации (не может быть представлено с 2 знаками после запятой)
- Хотя спецификация не явно запрещает 'inf', форматирование не соответствует требованиям

**Рекомендация:** Либо отклонить 'inf' на входе как невалидное значение (exit 1), либо обработать в format_output() с ошибкой.
