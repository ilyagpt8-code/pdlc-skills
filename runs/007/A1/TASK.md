# Задание владельца: приложение tempconv (ансамбль A1)

Напишите утилиту `tempconv` строго по спецификации `out/006-A1/tempconv.md`. Язык — Python 3 (стандартная библиотека). Код — `out/007-A1/tempconv.py`, тесты (pytest) — `out/007-A1/tests/`. Запуск: `python out/007-A1/tempconv.py <аргументы>` (пути от корня репозитория).

Спецификацию **не меняйте**. Если в ней пробел или противоречие — запишите в `runs/007/A1/spec-issues.md` и примите разумное решение, отметив его. Программа не должна падать с трейсбеком ни на каком вводе.
