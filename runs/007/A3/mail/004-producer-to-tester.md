# Producer to Tester: Метрика прогресса

## Ситуация

Команда работает, но у нас **нет метрики** — невозможно видеть прогресс по числам. Программа написана и тесты внутренние проходят, но нам нужна **независимая проверка** по твоим 40 тестовым случаям.

## Что нужно

Запусти свои 40 тестовых случаев из `tester-checks.md` и подсчитай, сколько **не прошли**. Это и будет метрика прогресса.

**Формат записи в журнал** (после каждой проверки):
```
метрика: тестов_не_пройдено=N [источник: проверка тестировщика, версия 1]
```

где N — количество тестов, которые **не соответствуют** требованиям спецификации.

Пример: если 3 теста не прошли, пишешь:
```
метрика: тестов_не_пройдено=3 [источник: проверка тестировщика, версия 1]
```

## Успех

После каждого хода — одна строка в журнал с числом. Когда число дойдет до 0, работа закончена.

Спасибо!
