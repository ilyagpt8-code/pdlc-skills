# Тестовые случаи для tempconv (версия 1)

## Базовые преобразования между шкалами

1. `tempconv 0 C F` — Цельсий в Фаренгейт: должен быть 32 F
2. `tempconv 32 F C` — Фаренгейт в Цельсий: должен быть 0 C
3. `tempconv 0 C K` — Цельсий в Кельвин: должен быть 273.15 K
4. `tempconv 273.15 K C` — Кельвин в Цельсий: должен быть 0 C
5. `tempconv 32 F K` — Фаренгейт в Кельвин: должен быть 273.15 K
6. `tempconv 273.15 K F` — Кельвин в Фаренгейт: должен быть 32 F

## Преобразование во все шкалы (когда to_scale не указана)

7. `tempconv 0 C` — Цельсий, все шкалы: должны быть строки с F и K (без C)
8. `tempconv 32 F` — Фаренгейт, все шкалы: должны быть строки с C и K (без F)
9. `tempconv 273.15 K` — Кельвин, все шкалы: должны быть строки с C и F (без K)

## Точки раздела (граничные значения)

10. `tempconv -273.15 C F` — Абсолютный нуль в Цельсии: -459.67 F
11. `tempconv -459.67 F C` — Абсолютный нуль в Фаренгейте: -273.15 C
12. `tempconv 0 K C` — Абсолютный нуль в Кельвинах: -273.15 C
13. `tempconv 100 C F` — Точка кипения воды: 212 F
14. `tempconv 212 F C` — Точка кипения воды: 100 C

## Отрицательные значения

15. `tempconv -50 C F` — Отрицательный Цельсий: преобразование должно работать
16. `tempconv -50 F C` — Отрицательный Фаренгейт: преобразование должно работать
17. `tempconv -100 C F` — Отрицательный Цельсий ближе к абсолютному нулю

## Научная нотация и малые значения

18. `tempconv 1e2 C F` — Научная нотация (100): преобразование должно работать
19. `tempconv 0.5 C F` — Малое положительное значение
20. `tempconv 0.001 C F` — Очень малое значение
21. `tempconv 1.5e-3 C F` — Научная нотация с малым значением

## Регистр шкал

22. `tempconv 0 c F` — Нижний регистр from_scale
23. `tempconv 0 C f` — Нижний регистр to_scale
24. `tempconv 0 c f` — Оба нижний регистр
25. `tempconv 0 C F` — Оба верхний регистр (уже есть)

## Ошибки: неверное число

26. `tempconv abc C F` — Не число в value: ошибка код 2
27. `tempconv 1.2.3 C F` — Невалидный формат числа: ошибка код 2
28. `tempconv +1.5 C F` — Знак плюс в числе (спецификация не упоминает)

## Ошибки: неверная шкала

29. `tempconv 0 R F` — Неизвестная from_scale: ошибка код 2
30. `tempconv 0 C R` — Неизвестная to_scale: ошибка код 2
31. `tempconv 0 Celsius F` — Полное слово вместо буквы: ошибка код 2
32. `tempconv 0 CC F` — Несколько букв: ошибка код 2

## Ошибки: температуры ниже абсолютного нуля

33. `tempconv -300 C F` — Ниже абсолютного нуля в Цельсии: ошибка код 3
34. `tempconv -500 F C` — Ниже абсолютного нуля в Фаренгейте: ошибка код 3
35. `tempconv -1 K C` — Ниже абсолютного нуля в Кельвинах: ошибка код 3

## Ошибки: аргументы

36. `tempconv 100` — Недостаточно аргументов (только значение, нет from_scale): ошибка код 1
37. `tempconv 100 C F K` — Слишком много аргументов: ошибка код 1
38. `tempconv` — Вообще нет аргументов: ошибка код 1

## Дополнительно: точность и округление

39. `tempconv 0.125 C F` — Половина единицы в дробной части
40. `tempconv 32 F F` — From и to одинаковые - спецификация не запрещает
