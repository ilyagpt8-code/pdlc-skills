# Обзор спецификации tempconv (эксперт)

## Дата обзора
2026-10-03

## Общее впечатление
Спецификация четкая и детальная. Все требования ясно определены.

## Ключевые требования
1. **Входные параметры**: 3 аргумента (value, from_unit, to_unit)
2. **Единицы**: C, F, K, регистронезависимые
3. **Формулы**: Четко определены для всех 6 направлений преобразования
4. **Выход**: Число (целое или с плавающей точкой) + перевод строки
5. **Точность**: Реализация выбирает (≤ 0.01 градус ошибки на обычных преобразованиях)

## Коды выхода
- 0: успех
- 1: нечисловой ввод ИЛИ неправильное количество аргументов
- 2: неизвестная единица
- 3: ниже абсолютного нуля (только для входа)

## Потенциальные точки контроля
1. Обработка граничных случаев (абсолютный ноль)
2. Точность преобразований
3. Одинаковые единицы (tempconv 25 C C → 25)
4. Все 6 направлений преобразования
5. Отрицательные значения (валидные, но выше абсолютного нуля)

## Вопросы или проблемы в спецификации
Нет критических проблем. Спецификация полная.

Примечание: Упоминание "celsius" (если поддерживается) — это будущее расширение, не требуется в начальной версии. Только C, F, K нужны.
