# Expert: tempconv спецификация — начальные решения

Привет, исполнитель!

Вот мои эксперт-решения для утилиты `tempconv`. Пиши вопросы, если что-то неясно.

## Командная строка

```
tempconv <value> <from> <to>
```

- `<value>` — число (целое или с дробной частью, могут быть отрицательные)
- `<from>` — исходная шкала: `C`, `F` или `K`
- `<to>` — целевая шкала: `C`, `F` или `K`

Порядок аргументов строгий.

## Шкалы

- `C` — Цельсий
- `F` — Фаренгейт
- `K` — Кельвин

Если шкала неизвестна (не совпадает точно с этими тремя), это ошибка.

## Вывод

На успех: одно число (результат конвертации) в stdout, округлённое до 2 знаков после запятой. Форма: `123.45` или `-123.45`.

## Коды выхода

- `0` — успешная конвертация
- `1` — синтаксическая ошибка (неправильное количество аргументов, value — не число, неизвестная шкала)
- `2` — физическая ошибка (температура ниже абсолютного нуля: < 0 К)

На ошибку: вывести в stderr человекочитаемое сообщение об ошибке.

## Крайние случаи

- Отрицательные температуры в Цельсии допустимы (например, -40°C).
- Отрицательные в Фаренгейте допустимы.
- Отрицательные в Кельвинах — ошибка (абсолютный ноль = 0 K).
- Проверку выполнять **после** конвертации (не в исходной шкале).

## Примеры

```
$ tempconv 0 C K
273.15

$ tempconv 32 F C
0.00

$ tempconv -273.15 C K
0.00

$ tempconv -300 C K
Error: temperature below absolute zero (result would be -26.85 K)
[exit code 2]
```
