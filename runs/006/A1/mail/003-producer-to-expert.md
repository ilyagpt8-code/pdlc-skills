# Метрика спецификации для tempconv

Исполнитель завершил спецификацию (out/006-A1/tempconv.md). Чтобы видеть прогресс, нужна метрика.

Предлагаю: **количество неясностей и пропусков в спецификации**, которые помешали бы другой команде написать программу без вопросов.

**Задача для эксперта:**
1. Прочитай спецификацию (out/006-A1/tempconv.md)
2. Сравни с требованиями из задания владельца (TASK.md)
3. Проверь против твоих решений (mail/001-expert-to-executor.md)
4. Подсчитай: сколько моментов остаются неясными или неполными? Это могут быть:
   - неоднозначные требования
   - противоречия
   - пропущенные граничные случаи
   - неясные формулировки

Напиши в журнал ансамбля (journal.md) строку:
```
метрика: неясностей_в_спеке=N [источник: проверка эксперта, раунд 1]
```

Где N — количество найденных неясностей (ноль значит спека полна и готова).

Спасибо.
