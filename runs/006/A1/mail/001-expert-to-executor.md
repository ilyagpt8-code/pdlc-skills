# Решения эксперта: спецификация tempconv

## Синтаксис команды

```
tempconv <value> <from> <to>
```

Где:
- `<value>` — число (целое или с десятичной точкой)
- `<from>` — исходная шкала: `C`, `F` или `K`
- `<to>` — целевая шкала: `C`, `F` или `K`

Пример: `tempconv 32 F C` → `0` (32°F = 0°C)

## Формулы конверсии

Стандартные физические формулы:
- **F ↔ C**: F = C × 9/5 + 32; C = (F - 32) × 5/9
- **K ↔ C**: K = C + 273.15; C = K - 273.15
- **F ↔ K**: цепочка через C

## Ошибки и коды выхода

| Ошибка | Код выхода | Сообщение (примерно) |
|--------|-----------|----------------------|
| Неверное количество аргументов | 2 | `Usage: tempconv <value> <from> <to>` |
| Значение — не число | 1 | `Error: invalid temperature value` |
| Неизвестная шкала | 1 | `Error: unknown scale` |
| Температура ниже абсолютного нуля | 1 | `Error: temperature below absolute zero` |

**Абсолютный ноль:**
- -273.15°C
- -459.67°F
- 0 K (точно)

Проверка: если результат ниже абсолютного нуля — ошибка.

## Формат вывода

- **Успех**: одно число (результат конверсии)
- **Ошибка**: сообщение об ошибке в stderr, пусто в stdout

## Точность и округление

- Вывод: с точностью до 2 знаков после запятой (для C и F) или 2 знака (для K)
- Убирать лишние нули: `0.00` → `0`, но `0.50` → `0.5`, `0.05` остаётся `0.05`

## Поведение на граничных случаях

1. Конверсия шкалы в саму себя (например, `tempconv 0 C C`) → `0`
2. Очень большие числа — обрабатывать как есть (проверить только абсолютный ноль)
3. Пробелы в аргументах — одиночные пробелы между аргументами, остальное — часть значения

## Требования к реализации

- Язык: по выбору исполнителя
- Код выхода 0 при успехе, 1 при ошибке ввода, 2 при неверном синтаксисе
- Готовность к использованию в скриптах (предсказуемый формат вывода)
