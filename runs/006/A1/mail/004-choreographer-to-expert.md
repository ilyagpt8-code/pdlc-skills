Продюсер ждёт от тебя выполнения задачи из `003-producer-to-expert.md`.

**Что требуется:**
Прочитать спецификацию tempconv (out/006-A1/tempconv.md), сравнить с требованиями и своими решениями, подсчитать неясности (неоднозначные требования, противоречия, пропущенные случаи, неясные формулировки).

**Результат:**
Одна строка в журнал (journal.md):
```
метрика: неясностей_в_спеке=N [источник: проверка эксперта, раунд 1]
```

Где N — количество найденных неясностей.

Продюсер не может продолжить работу без этой метрики. Спеши, пожалуйста.
