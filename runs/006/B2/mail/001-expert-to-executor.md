# Спецификация tempconv готова

Спецификация утилиты `tempconv` готова и находится в `out/006-B2/tempconv.md`.

## Что определено:

- Синтаксис команды: `tempconv <value> <from_scale> <to_scale>`
- Три шкалы: C (Цельсий), F (Фаренгейт), K (Кельвин)
- Формулы конвертации для всех пар шкал
- Проверка абсолютного нуля (ошибка, если ниже 0 K)
- Коды выхода: 0 (успех), 1 (неверное число), 2 (неверная шкала), 3 (ниже абсолютного нуля), 4 (неверное кол-во аргументов)
- Формат вывода и обработка ошибок
- Case-insensitive масштабы
