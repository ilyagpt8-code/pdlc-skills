# Решения эксперта для спецификации tempconv

## Основные решения

### Синтаксис
- Команда: `tempconv <value> <from_scale> <to_scale>`
- Шкалы: `C`, `F`, `K` (прописные буквы)
- Пример: `tempconv 32 F C` → вернёт 0.00

### Точность и формат вывода
- Результат: число с 2 десятичными знаками
- Формат: просто число, готовое для парсинга в скриптах
- Примеры:
  - `tempconv 0 C F` → `32.00`
  - `tempconv 273.15 K C` → `0.00`
  - `tempconv 100 C K` → `373.15`

### Валидация входных данных
1. **Неверное количество аргументов** → exit 1, сообщение об ошибке на stderr
2. **Значение не является числом** → exit 2, описание ошибки
3. **Неизвестная шкала** (не C, F или K) → exit 3, описание ошибки
4. **Температура ниже абсолютного нуля**:
   - Абсолютный ноль: -273.15°C, -459.67°F, 0K
   - Отклонить с exit 4 и объяснением
5. **Некорректное преобразование** (другие ошибки) → exit 5

### Сообщения об ошибках
- Все сообщения на stderr
- Формат: `Error: <краткое описание>`
- Примеры:
  - `Error: Invalid argument count`
  - `Error: Value is not a number`
  - `Error: Unknown temperature scale: X`
  - `Error: Temperature below absolute zero`

### На успех
- exit 0
- Результат на stdout

## Уточнения
Остальные детали (точная реализация формул, обработка граничных случаев вроде очень больших чисел, поведение при интернет-отключении и т. п.) решает исполнитель при написании спецификации. Если вопросы — пиши.
