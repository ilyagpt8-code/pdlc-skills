# Спецификация утилиты `tempconv`

## Обзор

`tempconv` — консольная утилита для конвертации температур между шкалами Цельсия (C), Фаренгейта (F) и Кельвина (K). Утилита предназначена для использования в скриптах и имеет предсказуемый формат вывода и кодов выхода.

## Синтаксис

```
tempconv <value> <from_scale> <to_scale>
```

### Аргументы

- `<value>` — числовое значение температуры (целое число, число с плавающей точкой, включая отрицательные значения)
- `<from_scale>` — исходная шкала температуры: `C`, `F` или `K` (только прописные буквы)
- `<to_scale>` — целевая шкала температуры: `C`, `F` или `K` (только прописные буквы)

## Примеры использования

### Успешные преобразования

```
$ tempconv 0 C F
32.00

$ tempconv 32 F C
0.00

$ tempconv 273.15 K C
0.00

$ tempconv 100 C K
373.15

$ tempconv -40 C F
-40.00

$ tempconv 98.6 F C
37.00
```

## Выходные данные

### На успех (exit 0)

- Результат выводится на **stdout** в виде одного числа с **ровно 2 десятичными знаками**
- Формат: `XXX.YY` (без дополнительного текста, пробелов или пояснений)
- Пример: `32.00`, `0.00`, `-40.00`, `273.15`

### Сообщения об ошибках

- Все сообщения об ошибках выводятся на **stderr**
- Формат: `Error: <краткое описание>`
- Примеры сообщений:
  - `Error: Invalid argument count`
  - `Error: Value is not a number`
  - `Error: Unknown temperature scale: X`
  - `Error: Temperature below absolute zero`
  - `Error: Conversion error`

## Коды выхода

| Код | Ситуация | Пример |
|-----|----------|--------|
| 0 | Успешное преобразование | `tempconv 0 C F` |
| 1 | Неверное количество аргументов | `tempconv 0 C` (не хватает аргумента) |
| 2 | Значение не является числом | `tempconv abc C F` |
| 3 | Неизвестная шкала | `tempconv 0 C X` (X не является C, F или K) |
| 4 | Температура ниже абсолютного нуля | `tempconv -300 C K` |
| 5 | Прочие ошибки преобразования | Внутренние ошибки |

## Валидация входных данных

### 1. Количество аргументов

- Утилита требует ровно 3 аргумента: значение, исходная шкала, целевая шкала
- Если аргументов меньше или больше → **exit 1** с сообщением `Error: Invalid argument count`

### 2. Значение температуры

- Должно быть корректным числом (целым числом или числом с плавающей точкой)
- Поддерживаются отрицательные значения
- Если значение не является числом → **exit 2** с сообщением `Error: Value is not a number`

### 3. Шкалы температуры

- Допустимые шкалы: `C` (Цельсий), `F` (Фаренгейт), `K` (Кельвин)
- Только прописные буквы
- Если шкала содержит пропись или неизвестна → **exit 3** с сообщением `Error: Unknown temperature scale: <указанное значение>`

### 4. Абсолютный ноль

- Абсолютный ноль — это минимально возможная температура в природе:
  - В Цельсиях: -273.15°C
  - В Фаренгейтах: -459.67°F
  - В Кельвинах: 0K
- Если введённое значение в исходной шкале ниже абсолютного нуля → **exit 4** с сообщением `Error: Temperature below absolute zero`
- Примеры отклонения:
  - `tempconv -274 C K` → ниже -273.15°C
  - `tempconv -460 F C` → ниже -459.67°F
  - `tempconv -1 K C` → ниже 0K

## Формулы преобразования

### Из Цельсия

- Цельсий → Фаренгейт: `F = C × 9/5 + 32`
- Цельсий → Кельвин: `K = C + 273.15`

### Из Фаренгейта

- Фаренгейт → Цельсий: `C = (F - 32) × 5/9`
- Фаренгейт → Кельвин: `K = (F - 32) × 5/9 + 273.15`

### Из Кельвина

- Кельвин → Цельсий: `C = K - 273.15`
- Кельвин → Фаренгейт: `F = (K - 273.15) × 9/5 + 32`

### Прямое преобразование (одна шкала в ту же)

- Если исходная и целевая шкалы совпадают, результат равен исходному значению
- Пример: `tempconv 32 F F` → `32.00`

## Примеры ошибок

```
# Неверное количество аргументов
$ tempconv 32 F
Error: Invalid argument count
(exit 1)

# Значение не является числом
$ tempconv abc C F
Error: Value is not a number
(exit 2)

# Неизвестная шкала
$ tempconv 0 C X
Error: Unknown temperature scale: X
(exit 3)

# Температура ниже абсолютного нуля
$ tempconv -300 C K
Error: Temperature below absolute zero
(exit 4)

# Слишком много аргументов
$ tempconv 32 F C extra
Error: Invalid argument count
(exit 1)

# Пропись в названии шкалы (не поддерживается)
$ tempconv 32 f C
Error: Unknown temperature scale: f
(exit 3)
```

## Требования к реализации

1. **Округление**: Результат должен округляться до ровно 2 десятичных знаков (стандартное арифметическое округление)
2. **Точность вычислений**: Использовать стандартные операции с числами с плавающей точкой
3. **Потокобезопасность**: Не требуется (утилита работает с одним вызовом за раз)
4. **Производительность**: Преобразование должно быть мгновенным (< 1мс)
5. **Зависимости**: Минимальные (нет требования к внешним библиотекам)

## Тестовые сценарии

### Нормальные случаи

- Преобразование между любыми двумя шкалами
- Нулевые значения
- Отрицательные значения (но выше абсолютного нуля)
- Большие значения
- Значения с дробной частью

### Граничные случаи

- Абсолютный ноль (должна приниматься ровно -273.15 для C, -459.67 для F, 0 для K)
- Значения очень близко к абсолютному нулю (чуть выше)
- Значения ниже абсолютного нуля
- Одинаковые исходная и целевая шкалы

### Ошибки

- Отсутствие аргументов
- Избыток аргументов
- Нечисловые значения
- Неизвестные шкалы
- Пропись в названиях шкал
- Пустые строки в аргументах
