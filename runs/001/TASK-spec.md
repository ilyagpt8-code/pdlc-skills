# Задание владельца: спецификация утилиты tempconv (ансамбль spec)

Нужна спецификация консольной утилиты `tempconv` — конвертера температур между шкалами Цельсия (C), Фаренгейта (F) и Кельвина (K). Спецификация должна быть такой, чтобы по ней **другая команда** без вопросов написала программу и тесты.

Результат: файл `spec/tempconv.md`.

Что важно пользователю утилиты:
- перевод значения из одной шкалы в другую одной командой;
- понятная реакция на неверный ввод (не число, неизвестная шкала, температура ниже абсолютного нуля);
- предсказуемый формат вывода и коды выхода, чтобы утилиту можно было вызывать из скриптов.

Остальное (точный синтаксис, округление, крайние случаи) решает команда.

## Роли
- **expert** (эксперт): решает, что входит в утилиту и как она себя ведёт; отвечает на вопросы исполнителя; принимает спецификацию. Не пишет `spec/tempconv.md` сам.
- **executor** (исполнитель): пишет `spec/tempconv.md` по решениям эксперта; задаёт вопросы эксперту. Не меняет решения эксперта сам.
- **producer** (продюсер): скилл `producer`.
- **choreographer** (хореограф): скилл `choreographer`.

Общие правила — `runs/001/COMMON.md`. Ансамбль — `spec`, почта — `runs/001/spec/mail/`.
