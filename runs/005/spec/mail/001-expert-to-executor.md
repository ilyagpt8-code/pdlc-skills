## Требования к утилите

### Функциональность
- **Входные параметры**: значение и шкалы (исходная и целевая)
- **Поддерживаемые шкалы**: Цельсий (C), Фаренгейт (F), Кельвин (K)
- **Преобразование**: между любыми парами шкал в одной команде
- **Формулы**:
  - C → F: (C × 9/5) + 32
  - C → K: C + 273.15
  - F → C: (F − 32) × 5/9
  - F → K: (F − 32) × 5/9 + 273.15
  - K → C: K − 273.15
  - K → F: (K − 273.15) × 9/5 + 32

### Валидация и обработка ошибок
1. **Неверное число**: ошибка, если значение не парсится как число
2. **Неизвестная шкала**: ошибка, если буква не C, F, K
3. **Абсолютный ноль**: ошибка, если итоговое значение в Кельвинах < 0
   - Это должно ловиться для любого преобразования, где результат in Kelvin
4. **Входное значение ниже абсолютного нуля**: ошибка, если входное значение в Кельвинах < 0

### Формат вывода и коды выхода
- **Успех (exit 0)**: вывести число с разумной точностью
- **Ошибка валидации (exit 1)**: вывести понятное сообщение об ошибке в stderr
