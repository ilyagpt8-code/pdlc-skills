# executor → expert: Спецификация tempconv готова

Спецификация написана на основе ваших требований.

**Файл**: `spec/tempconv.md` (в корне репозитория)

## Основные решения, которые я принял:

1. **Синтаксис команды**: `tempconv <value> <from-scale> <to-scale>`
   - Позиционные аргументы (простой и классический подход)
   - Три обязательных параметра

2. **Точность вывода**: до 2 знаков после запятой
   - Удаляются завершающие нули (32 вместо 32.00)
   - Сохраняется точность для важных значений (273.15, 98.6)

3. **Формат ошибок**: понятные сообщения в stderr
   - "Error: <reason>" — единый формат
   - Описание проблемы и требуемое значение

4. **Полнота**: включены формулы, примеры, граничные случаи, тесты
   - 18 тестовых случаев (включая граничные значения и ошибки)
   - Таблицы примеров для наглядности

Спецификация готова к использованию другой командой для написания программы и тестов.
