# tempconv — Спецификация консольной утилиты конвертера температур

## Обзор

`tempconv` — консольная утилита для конвертирования значений температуры между тремя шкалами: Цельсия (C), Фаренгейта (F) и Кельвина (K). Утилита предоставляет простой и предсказуемый интерфейс, подходящий для использования в скриптах и пайплайнах.

## Интерфейс команды

### Синтаксис

```
tempconv <value> <from> <to>
```

### Параметры

- **`<value>`** — числовое значение температуры для конвертирования
  - Может быть целым числом (например, `32`) или числом с десятичной точкой (например, `98.6`)
  - Пробелы вокруг числа не допускаются (они интерпретируются как разделители аргументов)

- **`<from>`** — исходная шкала (одна из: `C`, `F`, `K`)
  - `C` — Цельсий
  - `F` — Фаренгейт
  - `K` — Кельвин
  - Регистр: точно как указано (прописные буквы)

- **`<to>`** — целевая шкала (одна из: `C`, `F`, `K`)
  - Аналогично `<from>`

### Примеры использования

```bash
tempconv 32 F C       # 32°F → Цельсий → выведет: 0
tempconv 0 C F        # 0°C → Фаренгейт → выведет: 32
tempconv 273.15 K C   # 273.15 K → Цельсий → выведет: 0
tempconv 0 C C        # Конверсия в себя → выведет: 0
```

## Формулы конвертирования

Все конверсии производятся в соответствии со стандартными физическими формулами:

### Цельсий ↔ Фаренгейт
- **Из Цельсия в Фаренгейт:** F = C × 9/5 + 32
- **Из Фаренгейта в Цельсий:** C = (F − 32) × 5/9

### Цельсий ↔ Кельвин
- **Из Цельсия в Кельвин:** K = C + 273.15
- **Из Кельвина в Цельсий:** C = K − 273.15

### Фаренгейт ↔ Кельвин
- Конверсия производится через Цельсий (цепочка вычислений)

## Формат вывода

### При успехе
- Программа выводит в stdout единственное число — результат конвертирования
- Число выводится без единиц измерения и дополнительного текста
- stderr остаётся пустым
- Код выхода: 0

### При ошибке
- Программа выводит описание ошибки в stderr (см. раздел "Обработка ошибок")
- stdout остаётся пустым
- Код выхода: не равен 0 (см. таблицу ниже)

## Точность и округление

### Правила округления и форматирования

1. **Результат выводится с точностью до 2 знаков после запятой** (для всех шкал: C, F, K)

2. **Убирать лишние нули справа:**
   - `0.00` → `0` (если оба знака после запятой нули)
   - `0.50` → `0.5` (если только второй ноль)
   - `0.05` → `0.05` (остаётся как есть, если оба знака значимы)
   - `1.20` → `1.2`

3. **Целые числа** выводятся без десятичной точки:
   - `32.00` → `32`

### Примеры форматирования

| Вычисленное значение | Вывод |
|---|---|
| 0.00 | 0 |
| 32.00 | 32 |
| 98.60 | 98.6 |
| 0.05 | 0.05 |
| 273.15 | 273.15 |

## Обработка ошибок

Утилита должна проверять корректность входных данных и рапортировать об ошибках с помощью кодов выхода и сообщений об ошибках.

### Таблица ошибок

| Условие ошибки | Код выхода | Сообщение в stderr (примерный вид) |
|---|---|----|
| Неверное количество аргументов (не 3 аргумента) | 2 | `Usage: tempconv <value> <from> <to>` |
| Первый аргумент не является числом | 1 | `Error: invalid temperature value` |
| Параметр `<from>` не является допустимой шкалой | 1 | `Error: unknown scale` |
| Параметр `<to>` не является допустимой шкалой | 1 | `Error: unknown scale` |
| Результат конвертирования ниже абсолютного нуля | 1 | `Error: temperature below absolute zero` |

### Абсолютный ноль

Абсолютный ноль — минимально возможная физическая температура:
- **В Цельсиях:** -273.15°C
- **В Фаренгейтах:** -459.67°F
- **В Кельвинах:** 0 K (точно)

**Правило проверки:** Если результат конвертирования оказывается ниже абсолютного нуля (т.е. < −273.15°C, < −459.67°F или < 0 K), программа должна вывести ошибку `temperature below absolute zero` и завершиться с кодом 1.

### Примеры ошибочных вводов

```bash
# Неверное количество аргументов
$ tempconv 32 F
# Exit code: 2
# stderr: Usage: tempconv <value> <from> <to>

# Некорректное значение
$ tempconv abc F C
# Exit code: 1
# stderr: Error: invalid temperature value

# Неизвестная шкала
$ tempconv 0 C X
# Exit code: 1
# stderr: Error: unknown scale

# Результат ниже абсолютного нуля
$ tempconv -300 C K
# Exit code: 1
# stderr: Error: temperature below absolute zero
```

## Граничные случаи и особенности

1. **Конверсия в саму себя**
   - `tempconv 0 C C` → вывести `0` (код выхода 0)
   - Результат всегда равен входному значению (после форматирования)

2. **Большие числа**
   - Программа должна обрабатывать любые числовые значения, не ограничивая их величину (кроме проверки абсолютного нуля)
   - Потеря точности из-за ограничений типа данных — ответственность реализатора, но результат должен быть физически правдоподобен

3. **Отрицательные значения**
   - Поддерживаются отрицательные значения температуры (до абсолютного нуля включительно)
   - `-40 C` корректен (−40°C = −40°F)
   - `-274 C` вызовет ошибку (ниже абсолютного нуля)

4. **Десятичные значения**
   - Входное значение может содержать произвольное количество знаков после запятой
   - Вывод округляется согласно правилам округления (раздел выше)

5. **Пробелы**
   - Должно быть ровно по одному пробелу между аргументами
   - Лишние пробелы или отсутствие пробелов → ошибка "неверное количество аргументов"

## Требования к реализации

### Язык программирования
- Язык реализации выбирает разработчик (на основе контекста проекта)
- Требуется, чтобы программа была исполняемой из командной строки

### Кодирование символов
- Входные данные: UTF-8 или ASCII
- Выходные данные: ASCII (числа и сообщения об ошибках)

### Платформа
- Должна работать на Linux/Unix-совместимых системах
- Должна быть вызываема из shell-скриптов

### Использование в скриптах
Утилита разработана для встраивания в скрипты и пайплайны. Поэтому:
- Коды выхода должны быть предсказуемы и соответствовать таблице
- Формат вывода должен быть стабилен (число или ошибка, без лишнего текста)
- stderr и stdout должны использоваться корректно (ошибки → stderr, результат → stdout)
