# Спецификация утилиты tempconv

Консольная утилита для конвертации температур между шкалами Цельсия, Фаренгейта и Кельвина.

## Обзор

`tempconv` принимает значение температуры в одной шкале и выводит эквивалент в другой шкале. Утилита предсказуема в поведении и безопасна для использования в скриптах.

## Интерфейс командной строки

### Синтаксис

```
tempconv <value> <from> <to>
```

### Аргументы

- `<value>` — числовое значение температуры
  - Может быть целым числом (например, `0`, `32`, `-40`)
  - Может быть числом с дробной частью (например, `98.6`, `-273.15`)
  - Может быть отрицательным (например, `-40`)
  - Десятичный разделитель: точка (`.`)

- `<from>` — исходная шкала (обязательна)
  - Допустимые значения: `C`, `F`, `K` (регистр чувствителен)
  - `C` — Цельсий
  - `F` — Фаренгейт
  - `K` — Кельвин

- `<to>` — целевая шкала (обязательна)
  - Допустимые значения: `C`, `F`, `K` (регистр чувствителен)
  - `C` — Цельсий
  - `F` — Фаренгейт
  - `K` — Кельвин

### Порядок аргументов

Порядок аргументов **строгий**: значение, затем исходная шкала, затем целевая шкала. Любой другой порядок является ошибкой.

## Шкалы температуры

### Определения

- **Цельсий (C)** — шкала температур, где 0°C соответствует точке замерзания воды, а 100°C — точке кипения воды при нормальном атмосферном давлении. Может быть отрицательный.

- **Фаренгейт (F)** — шкала температур, используемая в англоговорящих странах. 32°F = 0°C, 212°F = 100°C. Может быть отрицательный.

- **Кельвин (K)** — абсолютная шкала температур, используемая в физике и инженерии. 0 K = абсолютный ноль. **Не может быть отрицательный.**

### Абсолютный ноль

Абсолютный ноль — это наименьшая возможная температура во вселенной:
- 0 K
- -273.15°C
- -459.67°F

Никакая физическая температура не может быть ниже абсолютного нуля.

## Формулы конвертации

### Из Цельсия в другие шкалы

- **C → F:** `F = C × 9/5 + 32`
- **C → K:** `K = C + 273.15`

### Из Фаренгейта в другие шкалы

- **F → C:** `C = (F - 32) × 5/9`
- **F → K:** `K = (F - 32) × 5/9 + 273.15`

### Из Кельвина в другие шкалы

- **K → C:** `C = K - 273.15`
- **K → F:** `F = (K - 273.15) × 9/5 + 32`

## Вывод

### Успешная конвертация

При успешной конвертации утилита выводит **одно число** в stdout:

- **Формат:** число с ровно 2 знаками после запятой
- **Примеры:** `273.15`, `0.00`, `-40.00`, `98.60`
- **Разделитель дробной части:** точка (`.`)
- **Знак:** может быть отрицательный (например, `-273.15`)

**Ровно одно число на одной строке. Никаких дополнительных текстов, комментариев или пояснений в stdout.**

### Ошибки

При ошибке утилита выводит в **stderr** человекочитаемое сообщение об ошибке и завершается с соответствующим кодом выхода.

- Сообщение об ошибке начинается с `Error: ` (с заглавной буквы E)
- Сообщение может содержать дополнительные детали (например, какое значение привело к ошибке)
- Вывод идет в stderr, не в stdout

**Пример:** `Error: invalid scale 'X' (expected C, F, or K)`

## Коды выхода

| Код | Условие | Примеры |
|-----|---------|---------|
| **0** | Успешная конвертация | `tempconv 0 C K` → выход 0 |
| **1** | Синтаксическая ошибка | Неправильное количество аргументов, значение не является числом, неизвестная шкала |
| **2** | Физическая ошибка | Результат конвертации < 0 K (ниже абсолютного нуля) |

### Примеры ошибок с выходом 1 (синтаксическая ошибка)

- `tempconv 0 C` — недостаточно аргументов
- `tempconv 0 C F extra` — слишком много аргументов
- `tempconv abc C F` — значение не является числом
- `tempconv 0 X F` — неизвестная исходная шкала
- `tempconv 0 C X` — неизвестная целевая шкала

### Примеры ошибок с выходом 2 (физическая ошибка)

- `tempconv -300 C K` — результат конвертации даст отрицательное значение в Кельвинах (ниже абсолютного нуля)
- `tempconv -500 F K` — результат конвертации даст отрицательное значение в Кельвинах

## Валидация и обработка ошибок

### Порядок проверок

1. **Количество аргументов:** проверить, что ровно 3 аргумента переданы (не больше, не меньше)
   - Если не 3 — выход 1

2. **Парсинг значения:** проверить, что `<value>` — корректное число (целое или с дробной частью, отрицательное или положительное)
   - Если не число — выход 1

3. **Валидация шкал:** проверить, что `<from>` и `<to>` — одно из значений `C`, `F`, `K` (регистр чувствителен)
   - Если не совпадают — выход 1

4. **Конвертация:** применить формулу конвертации

5. **Физическая валидация:** проверить, что результат конвертации не ниже абсолютного нуля (не < 0 K)
   - Если результат < 0 K — выход 2 с сообщением об ошибке

### Важное замечание: когда проверяется абсолютный ноль

Проверка на абсолютный ноль выполняется **после конвертации**, на результате в целевой шкале, а не на исходном значении.

**Пример:** при конвертации из Цельсия в Кельвин значение `-300°C` отрицательное в исходной шкале, но это не синтаксическая ошибка — синтаксис корректный. Утилита должна попытаться конвертировать и затем проверить результат. Результат конвертации: `-300 + 273.15 = -26.85 K` — это ниже абсолютного нуля, поэтому выход 2.

## Примеры использования

### Успешные конвертации

```bash
$ tempconv 0 C K
273.15
```

```bash
$ tempconv 32 F C
0.00
```

```bash
$ tempconv -273.15 C K
0.00
```

```bash
$ tempconv 100 C F
212.00
```

```bash
$ tempconv 0 K C
-273.15
```

```bash
$ tempconv 98.6 F C
37.00
```

### Ошибки (синтаксические, выход 1)

```bash
$ tempconv 0 C
Error: insufficient number of arguments
[выход: 1]
```

```bash
$ tempconv 0 C F extra
Error: too many arguments
[выход: 1]
```

```bash
$ tempconv abc C F
Error: value is not a valid number
[выход: 1]
```

```bash
$ tempconv 0 X F
Error: invalid scale 'X' (expected C, F, or K)
[выход: 1]
```

```bash
$ tempconv 0 C x
Error: invalid scale 'x' (expected C, F, or K)
[выход: 1]
```

### Ошибки (физические, выход 2)

```bash
$ tempconv -300 C K
Error: temperature below absolute zero (result would be -26.85 K)
[выход: 2]
```

```bash
$ tempconv -500 F K
Error: temperature below absolute zero (result would be -259.26 K)
[выход: 2]
```

## Округление

Результат всегда округляется до **ровно 2 знаков после запятой** при выводе.

- `273.156` выводится как `273.16` (математическое округление)
- `273.154` выводится как `273.15` (математическое округление)
- `273.00` выводится как `273.00` (два нулевых знака обязательны)

## Требования к реализации

### Общее

- Утилита должна быть портативной и работать без дополнительных зависимостей (стандартная библиотека языка)
- Все сообщения об ошибках должны начинаться с `Error: `
- Вывод результата всегда с 2 знаками после запятой

### Точность

- Для вычислений рекомендуется использовать числа с плавающей точкой (float/double/float64)
- Расчеты должны быть математически точными в пределах точности типа данных

### Обработка входных данных

- Пробелы в начале/конце аргументов допускаются (shell автоматически их убирает, но реализация может быть толерантна)
- Пустые аргументы считаются ошибкой (неверное значение или неверная шкала)
