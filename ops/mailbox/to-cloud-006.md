Прогон 001 — владелец одобрил (задание и пределы ниже). Ты в нём — **расписание**, а не участник: содержания в работу ансамбля не вносишь, на вопросы агентов не отвечаешь, ничего им не подсказываешь. Только запуск, ходы, коммиты, статистика, остановка, выгрузка.

Скиллы ролей переехали в `.claude/skills/producer` и `.claude/skills/choreographer`. Задания: `runs/001/TASK-spec.md`, `runs/001/TASK-app.md`, общие правила `runs/001/COMMON.md`.

## Ансамбль spec
1. Создай 4 сабагента (Agent, model haiku), стартовые поручения — дословно:
   - «Ты — expert в ансамбле spec. Задание владельца — runs/001/TASK-spec.md, общие правила — runs/001/COMMON.md. Прочитай оба. Это ход 1: сделай свою часть работы.»
   - то же для executor, producer («…Используй скилл producer.»), choreographer («…Используй скилл choreographer.»).
   Порядок в каждом круге: expert, executor, producer, choreographer. Запомни agentId каждого.
2. Круги 2…12: каждому по очереди SendMessage дословно «Ход N. Прочитай новую почту и сделай свою часть работы.» После каждого круга:
   - `git add -A runs spec app && git commit -m "run001 spec: круг N" && git push`;
   - сводка: `python tools/session_stats.py summary expert=<журнал> executor=<…> producer=<…> choreographer=<…> > runs/001/spec/stats.md` (журналы сабагентов `~/.claude/projects/.../subagents/agent-<id>.jsonl`; если чтение заблокировано — не обходи, напиши в stats.md «нет данных» и продолжай);
   - оценка расхода ансамбля по usage (цены Haiku 4.5).
3. Стоп, если: в `runs/001/spec/journal.md` есть строка `ГОТОВО:`; или прошло 12 кругов; или оценка расхода ансамбля > $1; или два круга подряд все четверо ничего не изменили в файлах. Перед стопом по любой причине, кроме ГОТОВО, дай продюсеру и хореографу ещё ход: «Работа останавливается (<причина>). Напиши свой разбор.»
4. Выгрузка: очищенные `tools/sanitize_journal.py` журналы сабагентов → `runs/001/journals/spec-<роль>.jsonl`; коммит, push.

## Ансамбль app
То же с `TASK-app.md`, ансамбль `app`, новые 4 сабагента, журналы `runs/001/journals/app-<роль>.jsonl`. Начинай, только если `spec/tempconv.md` существует (даже если spec остановился не по ГОТОВО). После стопа дополнительно запусти `python -m pytest app/tests -q` и запиши результат в `runs/001/app/pytest.txt`.
